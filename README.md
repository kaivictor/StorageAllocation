# 空间分配面板 · Storage Allocation

当你手里的存储越来越多——几块硬盘、几个网盘、几台 NAS、若干对象存储桶——「这份数据到底放在哪、占多大、访问频不频繁」就成了一笔糊涂账。

**空间分配面板**是一个帮你把这笔账理清的可视化工具：在一张画布上，把「存储空间」和「数据路径」摆两边，用连线把「哪个空间存了哪条路径」连起来，再为每条数据标注别名、访问频率、估计大小、用途与目录结构。谁属于谁，一眼看清。

---

## 它能帮你做什么

**存储介质**
- 为每个存储空间建立档案：账号、总容量、可用空间、规划容量、用途、备注一应俱全。
- 可更换内置图标，也能导入自己的图片当作空间图标，一眼区分不同存储。

**路径与数据**
- 右侧六列分别对应：**路径 / 数据别称 / 频率 / 估计大小 / 用途 / 结构**。
- 一条「数据记录」= 上述五项档案 + 一份**目录结构树**；结构树可逐层展开/折叠、随时增删子节点，把数据的内部形态也记下来。
- **路径天然成树**：输入 `/a/b/c/` 这样的完整路径，系统自动按层级归并父子关系；展示时只露出本级名称、父级以灰显前缀提示，层级越深缩进越大，树形结构自然浮现；悬停路径还能看到完整的父链。

**关联关系（核心）**
- **空间 ↔ 路径**：从任意一端的锚点拖一根线过去，就完成了一次归属绑定。
- **路径 ↔ 记录**：一条数据也能归属多条路径；关联会以「扇出」形式展开，关系网一目了然。
- **连线详情**：点开连线可填写同步方式、账号、密码、端口、备份策略与实际挂载路径，并用**状态**标注——正常 / 待备份 / 迁移出 / 迁移进，不同状态以不同颜色区分，便于跟踪每份数据的处置进度。

**专注与整理**
- **悬停聚焦**：鼠标移到任意对象上，相关的空间、路径、记录保持清晰，其余自动淡化（没有关联路径的孤立记录自身不会被弱化），帮你在繁杂中快速锁定关注的那一组关系。
- **自由排序**：长按每项左侧的 ⠿ 手柄即可拖动调整顺序；顺序随数据一起保存，右侧数据自动计算位置。

**安全与个性**
- **删除有保护**：右键删除空间 / 路径 / 记录 / 连线 / 结构节点时，危险操作需要二次确认，避免误删；删除路径时其子路径会自动上提一级，删除记录则只解除关联、不连累路径。
- **明暗主题**：右上角一键切换浅色 / 深色，选择会被记住。

## 几个顺手的设计

- **双击即改，单击即拷**：字段默认只读防误触；双击进入编辑（路径编辑的是完整路径），单击则把字段整体复制到剪贴板。
- **下拉即选**：频率、单位等枚举项双击弹出菜单直接选。
- **拖拽建立关联**：从空间或路径的锚点拖一根线到另一端，就完成了一次归属绑定；不喜欢随时右键解除。
- **纯前端、零部署**：无需服务器、无需联网，打开 `index.html` 即用，数据只留在你自己的浏览器里。

## 使用方法

上手只需要三步，其余功能随用随学：

1. **搭框架**：点顶部「+ 空间」「+ 数据」添加，或双击空白处新增记录。
2. **连关系**：从空间或路径的锚点 ⦿ 拖一根线到另一端，把「空间 ↔ 路径 ↔ 数据」绑起来；点路径右侧「+」可把某条数据直接挂到这条路径下。
3. **填档案**：双击任意字段补充别名、频率、大小、用途与目录结构；改路径时直接写完整路径，层级会自动归并。

日常管理也很轻量：

- **排序**：长按每项左侧的 ⠿ 手柄拖动即可，顺序自动保存。
- **聚焦**：鼠标悬停任意对象，相关项清晰、无关项淡化，快速看清一组关系。
- **备份**：「导出数据」下载 JSON 留底，「导入」随时恢复；右上角可切换明 / 暗主题。

> 字段默认只读防误触——双击才进入编辑，单击则把内容复制到剪贴板。

## 开发

纯前端、零依赖、无构建步骤。直接用浏览器打开 `index.html` 即可运行

### 技术栈

原生 HTML / CSS / JavaScript（ES5 风格、无框架、无打包器）。状态与视图均挂在全局，依赖 `<script>` 顺序加载。

### 目录与文件职责

```
index.html            入口；按顺序加载 CSS 与 JS
css/  base/layout/space/lanes/data/connections/overlays   各司其职的样式
js/state.js           单一 state 对象 + localStorage 持久化（saveState/loadState）
js/utils.js           通用工具：getByPath/setByPath、pstr/parr、getPath/getRecord、
                     enterPathEdit、autoParent、reorderPathFlat、statusClass
js/render.js          渲染管线：renderLeft / renderRight / 列宽同步 / 节点定位 /
                     drawRecordFrames；pathNodeHTML / spaceNodeHTML / structColumnHTML
js/connections.js     连线绘制 drawConnections、强调/弱化 emphasize、连线编辑 connEditorFields
js/data-ops.js        数据操作：导出/导入、增删空间·路径·记录、addRecordForPath、addPathRecord
js/events.js          事件委托：initEvents（change/click/dblclick/contextmenu/
                     mousedown/focusin/out）、拖拽连线 startDrag、长按重排、图标菜单
js/main.js            启动与主题：loadState → initEvents → render；明暗主题切换
```

### 数据模型

全局唯一的 `state`（`state.js`）保存在内存，并持久化到 `localStorage`（key `storage-allocation:v1`）：

- `spaces[]`：每个空间含 `info`（账号/容量/可用/规划/用途/备注）与 `media`（名称/图标）。
- `paths[]`：每条路径 `text` 为**完整绝对路径**（以 `/` 开头），`parent` 由 `autoParent` 按最长前缀匹配推导；叶子（不以 `/` 结尾）与子文件夹据此区分。
- `records[]`：每条数据含 `alias / freq / size{value,unit} / purpose / structure{name,children[]}`。
- `connections[]`：空间 ↔ 路径（多对多）。
- `pathRecords[]`：路径 ↔ 记录（多对多，扇出展开）。

### 本地运行

```
# 任选其一
直接双击 index.html
# 或起一个静态服务器（避免某些浏览器对 file:// 的限制）
python3 -m http.server 8080   # 然后访问 http://localhost:8080
或者是
npx serve l 8080
```

无测试框架、无 CI；逻辑分散在各 `js/*.js` 的全局函数中，调试可直接在浏览器控制台调用（如 `render()`、`state`）。

## 适合谁

- 在多个存储之间反复权衡「该放哪儿」的个人玩家；
- 需要向同事/客户直观说明「数据分布与容量规划」的运维或架构同学；
- 任何受够了用表格和脑子记路径的人。
- 未来，可以实在移动对应介质上的数据。
---

数据保存在本地浏览器（localStorage），所有改动实时落盘；重要资料记得用「导出数据」定期备份成 JSON 文件。
